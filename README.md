# 🧠 Davi Notes

Este repositório reúne minhas anotações de estudo sobre desenvolvimento de software, com foco em tecnologias como: 
**Backend utilizando Java e Spring Boot**, **Vue 3, TypeScript e Axios**, **Redes** e **Outras ferramentas**.

Ele funciona como uma **wiki técnica pessoal**, onde organizo conceitos, exemplos, boas práticas e aprendizados aplicados em projetos reais.

---

# 🚀 Objetivo

Centralizar o conhecimento adquirido ao longo dos estudos para:

* Revisar conceitos de forma rápida;
* Servir de apoio durante o desenvolvimento de projetos e trabalho;
* Documentar aprendizados e boas práticas;
* Acompanhar minha evolução em tecnologia;
