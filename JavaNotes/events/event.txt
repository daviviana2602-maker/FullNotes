================= RabbitMQ — Event =================


Um Event representa algo que aconteceu no sistema.

public record PixCompletedEvent(
        UUID pixId,
        UUID senderAccountId,
        UUID receiverAccountId,
        BigDecimal amount
) {
}


Exemplo:

PixCompletedEvent(
    pixId = 123,
    sender = 10,
    receiver = 20,
    amount = 500
)

Significado:

    "O PIX 123 foi concluído."



================= RabbitMQ — Producer =================


Producer é responsável por publicar mensagens.


@Service
public class PixEventProducer {

    private final RabbitTemplate rabbitTemplate;


    public PixEventProducer(RabbitTemplate rabbitTemplate) {
        this.rabbitTemplate = rabbitTemplate;
    }


    public void publish(PixCompletedEvent event) {
        rabbitTemplate.convertAndSend("pix.completed", event);
    }

}


rabbitTemplate
    → usado pelo Spring para enviar mensagens ao RabbitMQ.

convertAndSend(...)
    → envia a mensagem.



================= RabbitMQ — Consumer =================


Consumer recebe mensagens de uma Queue.


@Component
public class PixEventConsumer {

    @RabbitListener(queues = "pix.completed")
    public void consume(PixCompletedEvent event) {

        System.out.println(
                "PIX concluído: " + event.pixId()
        );

    }

}


@RabbitListener
    → faz o método escutar uma Queue.

@RabbitListener(queues = "pix.completed")
    → quando houver uma mensagem nessa fila, o método será executado.
