=============== FLUXO DockerFile =============== 


- Define como uma Docker Image será criada.


RUN mvn clean package -DskipTests
    1 - Maven compila, gera .class e empacota → gera .jar em target/   (pasta target é a pasta de build do Maven)


COPY --from=build /app/target/*.jar app.jar
    2 - Docker pega o .jar   ("executável" da aplicação Java)


ENTRYPOINT ["java", "-jar", "app.jar"]
    3 - Container executa java -jar app.jar



images como:

- postgres:15 
- redis:7-alpine

já existem (alguém já fez), então só são utilizadas no DockerCompose e não necessitam de um DockerFile próprio, diferente da aplicação Backend


=============== Docker Compose =============== 


Define e gerencia vários Containers (execuções das Images) que trabalham juntos.

Em vez de iniciar cada Container manualmente, o Docker Compose sobe todos de uma vez.


Exemplo:

    Projeto Spring Boot

            ↓

    docker-compose.yml

            ↓

    - Spring Boot
    - PostgreSQL
    - Redis


Tudo conectado automaticamente pela mesma rede.
