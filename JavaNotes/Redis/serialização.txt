=============== Serialização ===============


    @Configuration
    @EnableCaching
    public class RedisConfig {


        @Bean
        RedisCacheConfiguration cacheConfiguration() {

            // generic salva o tipo do objeto pra desserializar corretamente
            GenericJackson2JsonRedisSerializer serializer = new GenericJackson2JsonRedisSerializer();


            return RedisCacheConfiguration.defaultCacheConfig()
                    .serializeValuesWith(
                            RedisSerializationContext.SerializationPair.fromSerializer(serializer)
                    );
        }

    }



- Redis não entende JSON, Java ou objetos. Ele só guarda bytes, mas esses bytes representam um texto JSON.

- Dentro do Redis, fica uma sequência de bytes:   10101100 01101010 11100010 00101010 ...

- Por exemplo, o Redis poderia estar guardando algo que, quando interpretado, vira:


{
  "@class": "com.example.ProductPageResponse",      (formato pra desserializar com Generic)
  "products": [
    {
      "id": 1,
      "name": "Bolo"
    }
  ],
  "page": 0
}
