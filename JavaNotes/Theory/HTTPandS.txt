=============== HTTP and HTTPS =============== 



HTTP normal:

    Seu navegador
        |
        |  dados em texto puro
        |
     Servidor

Alguém no caminho (ex: uma rede Wi-Fi comprometida) poderia teoricamente interceptar a comunicação.



HTTP + TLS = HTTP criptografado = HTTPS é a versão segura do HTTP.


HTTPS:

    Seu navegador
        |
        |  dados criptografados 
        |
    Servidor

A comunicação é protegida por criptografia usando TLS.



Exemplo:

    fez login:

    POST /login

    email=davi@email.com
    password=123456


HTTP = transmitido pela rede entre o seu computador (cliente) e um servidor web sem proteção.

HTTPS = vai algo parecido com:  

    a8f72h19x91k2s...


Quem interceptar não consegue entender.
