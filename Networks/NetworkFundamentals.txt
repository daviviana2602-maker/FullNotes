==================== REDES, PROTOCOLOS E PACOTES ====================


Quando um computador precisa enviar informações para outro dispositivo, ele transmite dados através da rede.
Esses dados não são necessariamente enviados como um único bloco gigante.
Dependendo do protocolo, eles são organizados em unidades menores, como pacotes, que são transmitidos pela infraestrutura de rede até o destino.


- O que é uma Rede de computadores (computer network):
    Uma computer network é um grupo de dispositivos conectados entre eles para permitir a comunicação e o compartilhamento de informações, recursos e serviços.
    (Computers, Servers, Printers, Smartphones, Routers, Switches)


- O que são protocolos (protocol):
    Dispositivos utilizam protocolos de comunicação para estabelecer regras sobre como essas informações são compartilhadas, recebidas e interpretadas.


- O que são pacotes (packet): 
    É uma unidade de dados transmitida por uma rede utilizando o protocolo IP.
    Uma comunicação pode gerar vários pacotes, eles podem seguir caminhos diferentes.

    O pacote IP pode carregar um segmento TCP, um datagrama UDP ou uma mensagem ICMP. 
    Contém: 

    - IP de origem/destino
    - Protocolo de transporte (TCP/UDP/ICMP....)
    - Se o pacote tiver protocolo TCP ou UDP carrega: Porta de origem (Alguma porta temporária do computador) e porta de destino (varia de acordo com serviço)
    - Payload (dados sendo transportados)


- FLOW:

    1 - Usuário digita google.com: o navegador identifica o endereço que deseja acessar.
    2 - DNS: o computador resolve o domínio e obtém o IP do Google.

    3 - Dados, encapsulamento e criação dos pacotes:
        - Navegador prepara os dados HTTP que deseja enviar.
        - TCP organiza os dados em segmentos.
        - IP encapsula esses segmentos em pacotes IP.
        - Ethernet ou Wi-Fi encapsula os pacotes em quadros para transmissão local.

    4 - Computador envia os quadros ao Gateway, que recebe os pacotes IP e os encaminha ao destino.
    5 - Pacote passa por provedor e intermediários (cada roteador decide o próximo salto).
    6 - Os pacotes chegam ao servidor do Google, que entrega os dados à aplicação correspondente. O servidor processa a requisição e envia a resposta ao navegador.


==================== LAN, VLAN, WLAN E ETHERNET ====================


- O que é LAN (Local Area Network): 
    É uma rede que conecta dispositivos em uma área relativamente limitada.


- O que é VLAN (Virtual Local Area Network): 
    É uma forma de separar LANs, uma maneira de criar redes locais separadas usando a mesma infraestrutura física

    Temos: 1 switch físico - 10 computadores do financeiro - 10 computadores do TI.
    Podemos dividir em: VLAN 10 → Financeiro - VLAN 20 → TI


- O que é WLAN (Wireless Local Area Network)
    É uma LAN que utiliza comunicação sem fio, normalmente Wi-Fi.


- O que é Ethernet:
    Grupo de tecnologias e padrões de comunicação para redes locais, normalmente cabeadas.
    

- Podemos ter 12 dispositivos na ethernet com switch, 13 conectados na WLAN e todos estão na mesma LAN (na mesma rede)
